# 中国象棋

基于 HTML、CSS 和 JavaScript 的浏览器象棋项目，包含 PWA 相关配置。

## 入口
- 主页面：`index.html`
- [GitHub Pages 演示地址（旧目录记录，待现场核验）](https://z15314102792-arch.github.io/chinese-chess/)

## 本地运行
在项目目录启动静态文件服务器：

```bash
python -m http.server 8080
```

然后打开 `http://localhost:8080/`。如果只需快速查看界面，也可以直接打开 `index.html`；PWA/离线能力建议通过 HTTP 地址测试。
